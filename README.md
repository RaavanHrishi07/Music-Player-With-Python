# 🎵 Music Player with Python

A desktop-based music player application developed using **Python, Tkinter and Pygame**. It provides a simple graphical interface to browse music folders and play audio files with essential playback controls.

## ✨ Features

- 🎶 Browse and load music from local folders.
- 📂 Supports MP3, WAV and OGG audio formats.
- ▶️ Play selected songs.
- ⏸️ Pause and resume playback.
- ⏹️ Stop music playback.
- 🎨 Modern and colourful graphical interface.
- ⚠️ Error handling for invalid selections and playback issues.
- 🖱️ Double-click a song to play it.

## 🛠️ Technologies Used

- Python 3
- Tkinter
- Pygame
- OS Module

## 📋 Requirements

- Python 3.x
- Pygame

## 🚀 Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/RaavanHrishi07/Music-Player-With-Python.git
```

**2. Navigate to the project directory**

```bash
cd Music-Player-With-Python
```

**3. Install the required dependency**

```bash
pip install pygame
```

**4. Run the application**

```bash
python "Music Player With Python.py"
```

## 🎮 How to Use

1. Launch the application.
2. Click **Choose Music Folder**.
3. Select a folder containing your audio files.
4. Select a song from the playlist.
5. Use the playback buttons to play, pause, resume or stop music.
6. Double-click any song in the playlist for quick playback.
